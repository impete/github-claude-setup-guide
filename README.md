## 💡 Key Concepts

### Git
Version control system that tracks code changes locally on your Mac.

### GitHub
Cloud platform where you store and share Git repositories.

### SSH
Secure authentication method for GitHub access (better than passwords).

### Claude Code
AI assistant that helps with coding tasks through the terminal.

## ❓ FAQ

**Q: Do I need prior coding experience?**  
A: No! Start with **BEGINNER-GUIDE.md**. It's designed for complete beginners.

**Q: How long does setup take?**  
A: 30-60 minutes depending on your experience level.

**Q: Can I use Windows/Linux?**  
A: This guide is Mac-specific. The concepts apply elsewhere, but commands differ.

**Q: Do I need to pay for anything?**  
A: No! GitHub, Git, and Claude Code have free tiers.

**Q: What if I get stuck?**  
A: Check the troubleshooting section in your guide, or search the GitHub community.
